# KeaboEntle Website

Static, dependency-free website built from the supplied KeaboEntle NPO profile and the requested charity: water-inspired storytelling structure.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the entire folder to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages, or standard web hosting).

## Important before public launch
The supplied COR39 document states the enterprise status as "AR Deregistration Process". Confirm the current official status and update the transparency section before accepting donations.

No banking details or online payment processor were supplied, so the site intentionally does not invent payment details or simulate successful donations.
